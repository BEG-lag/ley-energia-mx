      04

      Con Claude, sin llaves

      El repositorio trae un servidor MCP de sólo lectura. Claude busca, lee el artículo completo y cita con documento, artículo y liga oficial, usando tu suscripción. El proyecto no usa ni pide llaves de ningún servicio.

      1. Clona e indexa

      git clone https://github.com/BEG-lag/ley-energia-mx
cd ley-energia-mx
uv sync
uv run ley-energia indexar

      El índice se arma en tu máquina con un modelo local de embeddings.

      2. Conéctalo

      Claude Code (dentro de la carpeta ya lo detecta por .mcp.json):

      claude mcp add ley-energia -- \
  uv --directory "$PWD" run ley-energia mcp

      Claude Desktop, en claude_desktop_config.json:

      "ley-energia": {
  "command": "uv",
  "args": ["--directory", "/ruta/a/ley-energia-mx",
           "run", "ley-energia", "mcp"]
}

      3. Pregunta

      • ¿Qué permisos necesita una planta solar de 30 MW con almacenamiento y quién los otorga?
      • ¿Qué decía la ley sobre el abasto aislado en 2020 y qué lo sustituyó?
      • Compara el autoconsumo de la LSE con su DACG de 2025.

      Trae tres prompts listos: due diligence, régimen temporal y regulación aplicable. Sin instalar nada, usa "Copiar para Claude" en los resultados.

      05

      Cómo funciona

      Un manifiesto declara cada documento y su fuente oficial. El texto se trocea por unidad jurídica y se indexa en un solo archivo SQLite con dos señales que se fusionan por rangos (RRF): léxica sobre raíces en español y vectorial con un modelo local. Dos señales más reconocen el artículo exacto y la ley nombrada.
